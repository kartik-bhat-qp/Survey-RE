# DeepDive Code Export

This export contains DeepDive-related frontend prototype code split by usage area.

## creator
Files used on the creator/editor side, including survey editing UI, DeepDive settings, question configuration, attached indicators, question reordering, and supporting mock data for authoring flows.

## respondent
Files used on the respondent/preview side, including the survey preview route, question preview components, DeepDive conversation and follow-up UI, follow-up thread logic, and preview/session mock data.

## shared
This folder contains this README. Shared data/config files across creator and respondent are primarily the mock/config files copied into the export folders where they are used. If needed, these can be centralized further in a later pass based on actual reuse.
